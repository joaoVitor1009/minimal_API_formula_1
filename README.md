## 🚀 Tecnologias

- **Node.js:** ambiente de execução JavaScript.
- **TypeScript:** tipagem estática para um desenvolvimento mais seguro.
- **tsup / tsx:** ferramentas para compilação e execução do código TypeScript.

---

## 🏁 Como Executar

### Pré-requisitos

- [Node.js](https://nodejs.org/) instalado.
- npm, incluído na instalação do Node.js.
- Git instalado para clonar o repositório.

### Passos

**1. Clone o repositório**

```bash id="1jd5pl"
git clone https://github.com/joaoVitor1009/minimal_API_formula_1.git
cd minimal_API_formula_1
```

**2. Instale as dependências**

```bash id="2k3m9q"
npm install
```

**3. Execute a API em modo de desenvolvimento**

```bash id="3n4r8s"
npm run start:dev
```
